# QuickNotes

## Description

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It allows users to create notes, organise them into Personal, Work, and Study categories, search for notes, and delete notes they no longer need. Notes are saved in the browser's local storage so they remain available after refreshing the page.

## Features

* **Add notes:** Create notes with your own text.
* **Categories:** Organise notes into Personal, Work, and Study.
* **Delete notes:** Remove individual notes when they are no longer needed.
* **Search notes:** Find notes by searching for words or phrases, regardless of letter case.
* **Input validation:** Empty notes and notes longer than 200 characters are rejected.
* **Character limit:** Notes can contain up to 200 characters.
* **Note counter:** Displays the total number of saved notes.
* **Date and time:** Each note displays when it was created.
* **Local storage:** Notes remain saved after refreshing or reopening the page.
* **Responsive design:** The layout adapts to smaller screens.

## How to Run the Project Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/zainajoy/quicknotes-app.git
   ```

2. Open the project folder:

   ```bash
   cd quicknotes-app
   ```

3. Open `index.html` in your web browser.

   Alternatively, open the project in Visual Studio Code and use the Live Server extension to run it.

No additional packages or installations are required.
